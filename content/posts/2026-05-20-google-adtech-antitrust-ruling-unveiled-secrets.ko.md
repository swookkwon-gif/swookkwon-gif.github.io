# 독점의 알고리즘: 구글 반독점 소송 최종 판결과 비밀 프로젝트의 전말

> *"구글은 단순히 성능이 좋은 광고 도구를 만든 것이 아니다. 그들은 경매장(AdX)의 주인이자, 물건을 파는 대리인(DFP)이자, 물건을 사는 구매자(Google Ads/DV360)였으며, 자신들이 100% 이기도록 게임의 룰을 실시간으로 조작했다."*

2025년 4월, 미국 연방법원의 레오니 브린케마(Leonie Brinkema) 판사는 디지털 광고 역사상 가장 중대한 판결을 내렸습니다. 미국 법무부(DOJ)가 제기한 광고 기술(Ad Tech) 독점 소송에서 **"구글은 오픈웹 퍼블리셔 광고 서버 및 광고 거래소 시장에서 불법적인 독점 체제를 구축하고 유지했다"**며 유죄를 최종 선언한 것입니다.

이 재판 과정에서 구글이 대중과 광고주들에게 감추어 두었던 애드테크 블랙박스의 내부 코드명과 비밀 프로젝트들이 낱낱이 폭로되었습니다. 광고주들이 왜 불필요한 고비용을 지출해야 했고, 매체사들의 광고 수익은 왜 매년 줄어들 수밖에 없었는지, 그 독점 알고리즘의 실체를 파헤쳐 봅니다.

---

## 1. Project Bernanke: "경매장의 내부자 거래"

구글이 2013년에 가동한 **프로젝트 버넌케(Project Bernanke)**는 전 연방준비제도(Fed) 의장인 벤 버넌케의 이름에서 따온 내부 코드명입니다. 연준의 '양적 완화'처럼 애드테크 생태계 내부의 유동성(입찰 가격)을 인위적으로 조절했다는 의미에서 붙여진 이름입니다.

```
[ 일반적인 타사 DSP 입찰 ] ──▶ $5.00 입찰 ──────┐
                                                  ├──▶ 구글 거래소(AdX) 경매 진행
[ 구글 Ads 구매자 입찰 ] ──▶ $4.50 입찰 ──▶ (Project Bernanke 개입: 과거 데이터 분석 + 넛지 보정) ──▶ $5.10 낙찰!
                                                  │ (매체사에는 실제 수수료를 깎아 차액 메꿈)
```

### ❶ 작동 기작
버넌케의 본질은 **"경매장 주인이 특정 입찰자에게 경쟁자들의 패를 보여주고 입찰가를 넛지(Nudge)해 준 것"**입니다. 
구글은 자사의 광고 거래소(AdX)를 거쳐 간 수억 건의 과거 입찰 데이터를 독점적으로 활용했습니다. 구글의 광고 구매 도구(Google Ads)를 쓰는 광고주가 타사 DSP(예: 더 트레이드 데스크 등)를 쓰는 구매자와 경쟁할 때, 구글은 타사 입찰 예상가보다 단 1센트라도 높게 구글 광고주의 입찰가를 내부적으로 인위적으로 보정(Nudge)해 주었습니다.

### ❷ 비용의 왜곡과 매체사 착취
이 보정에 필요한 재원은 구글이 퍼블리셔(매체사)에게 지불해야 할 광고 정산 대금 중 일부를 수수료 명목으로 몰래 떼어내 만든 '공동 풀(Pool)'에서 충당되었습니다. 
결과적으로 구글 Ads를 쓰는 광고주는 경매에서 승리해 광고 노출을 독점했지만, 매체사는 광고 단가가 인위적으로 낮아져 **수익이 20-30% 감소**하는 피해를 보았습니다. 구글은 이 과정을 광고주나 매체사 양쪽에 전혀 공개하지 않았습니다.

## 2. Project Poirot: "헤더 비딩을 향한 90% 후려치기"

2016-2017년경, 구글의 독점에 대항하기 위해 매체사들은 **'헤더 비딩(Header Bidding)'**이라는 기술을 연합하여 도입했습니다. 구글의 광고 서버(DFP)가 입찰을 독점하기 전에, 여러 독립 광고 거래소들이 매체사의 지면을 두고 동시에 공정하게 경쟁 입찰을 벌일 수 있도록 하는 오픈소스 기술이었습니다. 

독점 체제에 균열이 생기자 구글은 즉각 대응책을 가동했습니다. 그것이 바로 애드테크 학살극이라 불리는 **프로젝트 푸아로(Project Poirot)**입니다.

```
[ 매체사 지면 입찰 요청 ]
        │
        ├──▶ 타사 거래소 라우팅 (헤더 비딩 사용 감지)
        │            │
        │            └─▶ [Project Poirot 발동] ──▶ 구글 구매 도구(DV360) 입찰가 최대 90% 강제 삭감
        │                                                │
        │                                                └─▶ 타사 거래소 낙찰 성공률 폭락 (수익성 악화)
        └──▶ 구글 자체 거래소(AdX) 라우팅 ───────▶ 정상 가격 입찰 및 낙찰
```

### ❶ 타사 거래소 입찰의 고의적 삭감
구글의 대형 광고주용 구매 툴인 DV360은 광고 지면을 살 때 최적의 가격을 찾아 입찰합니다. 프로젝트 푸아로는 DV360이 입찰하려는 광고 지면이 **구글 거래소가 아닌, 헤더 비딩을 사용하는 경쟁 거래소를 거쳐 들어오고 있음이 감지되면 입찰 가격을 최대 90%까지 스스로 낮추도록** 로직을 비틀었습니다.

### ❷ 결과: 경쟁 도구의 고사
입찰가가 90% 깎이니 경쟁 거래소들은 낙찰에 실패하기 시작했습니다. 매체사들은 *"헤더 비딩을 연동해 봤자 구글 광고주들의 입찰액이 바닥을 기는구나"*라고 판단하게 되었고, 결국 헤더 비딩을 포기한 채 구글의 시스템으로 다시 복귀했습니다. 구글은 자신의 구매 도구 점유율을 무기로 삼아 매체사의 판매 도구 경쟁사들을 고사시킨 것입니다.

## 3. Project Bell: "우선권을 주지 않는 자에게 내리는 징벌"

매체사들이 구글 Ad Manager(DFP) 외에 다른 애드테크 도구를 병행하여 쓰려고 시도하자, 구글은 채찍을 꺼내 들었습니다. **프로젝트 벨(Project Bell)**은 구글 거래소(AdX)에 독점적인 '우선 입찰 권한(First-Look)'을 주지 않는 매체사들에게 벌칙을 가하기 위해 설계되었습니다.

*   **징벌적 단가 조정:** 매체사가 타사 광고 서버나 독립 애드테크 벤더에게 먼저 입찰 기회를 줄 경우, 프로젝트 벨 알고리즘은 해당 매체사 지면에 제공하는 구글의 광고 입찰 단가를 **20-30% 강제로 인하**했습니다.
*   **고립 정책:** 매체사 입장에서는 구글의 압도적인 광고주 풀(Demand)을 잃으면 생존할 수 없었기에, 울며 겨자 먹기로 타사와의 협력을 끊고 구글에게 전적인 우선권을 넘겨줄 수밖에 없었습니다.

---

## 4. Jedi Blue: "메타(페이스북)와의 은밀한 거래"

소송 과정에서 드러난 가장 결정적인 담합 증거는 2018년 구글과 메타(당시 페이스북) 간에 맺어진 비밀 밀약, **제다이 블루(Jedi Blue)**였습니다.

당시 페이스북은 구글 독점망을 우회하기 위해 헤더 비딩 동맹의 최대 맹주로 나서려 했습니다. 위협을 느낀 구글은 페이스북과 이면 합의를 맺었습니다.

*   **구글의 약속:** 페이스북이 헤더 비딩 진영에서 철수하는 대가로, 구글 AdX 경매 참여 시 **입찰 속도 우대, 낙찰 성공률(Win-Rate) 일정 비율 보장, 그리고 수수료 감면(리베이트)** 혜택을 제공하겠다고 약속했습니다.
*   **메타의 배신:** 메타는 공정한 헤더 비딩 생태계를 팽개치고 구글의 가두리 양식장 안에서 VIP 특권을 누리는 길을 선택했고, 오픈웹의 공정 경쟁은 완전히 좌초되었습니다.

## 5. 결말: Tech Tax의 진실과 광고비 낭비

레오니 브린케마 판사는 판결문에서 구글이 구축한 애드테크 공급망 수수료가 시장의 자유 경쟁으로 형성된 정상적인 수수료가 아니라고 판단했습니다. 그것은 독점을 강제하여 뜯어낸 **독점 지대(Monopoly Rent)**, 즉 **테크 택스(Tech Tax)**였습니다.

```
[ 광고주의 광고 예산 $100 ]
        │
        ├─▶ 구글 광고 구매 도구 수수료 (Google Ads / DV360) : 약 15-20% 삭감
        ├─▶ 구글 광고 거래소 수수료 (AdX)                  : 약 20% 삭감
        ├─▶ 구글 퍼블리셔 광고 서버 수수료 (DFP)            : 약 10% 삭감
        │
        └─▶ 매체사(Publisher)가 받는 실제 광고 수익        : 단 $40-$50 내외
```

구글은 광고주가 100달러를 쓰면 매체사가 실제로 손에 쥐는 돈은 40-50달러에 불과한 시장을 만들어 냈습니다. 그 과정에서 발생하는 50%의 누수가 바로 구글이 설계한 비밀 프로젝트들과 수수료 구조(Tech Tax) 때문이었습니다.

### 마케터가 직시해야 할 팩트
구글의 대시보드에 표시되는 "최적화된 효율"과 "낮은 CPC/CPM" 뒤편에는, 경쟁사를 죽이기 위해 입찰 단가를 최대 90%까지 후려치고, 경쟁 입찰 정보를 내부적으로 도용하며, 매체사에게 징벌적 페널티를 부과해 온 불공정 경매 조작 알고리즘이 있었습니다.

그동안 마케터들이 'AI 알고리즘의 최적화 승리'라고 믿었던 성과의 상당 부분은, 실상 구글이 자신들의 도구가 이길 수밖에 없도록 설계해 놓은 인위적인 게임 판의 결과물이었습니다. 이제 우리는 광고 플랫폼의 대시보드 너머에 있는 **프로덕트 공급망 전체의 투명성**을 요구하고, 플랫폼 외부의 독립적인 검증 지표를 반드시 구축해야만 합니다.

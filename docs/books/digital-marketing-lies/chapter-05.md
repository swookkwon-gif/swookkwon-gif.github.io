# 5장. 애드테크 공급망과 국내 플랫폼의 한계

> *"우리가 보낸 광고비 1달러 중 매체사의 손에 쥐어지는 것은 단 50센트뿐이다. 나머지는 보이지 않는 애드테크 통행세로 증발했다."*

디지털 광고의 매력은 중간 마진이 없는 '직거래'처럼 느껴진다는 점이다. 광고주인 나와 페이스북, 혹은 나와 구글 사이에 중간 거간꾼 없이 곧장 연결된다고 믿는다. 

하지만 실제 프로그래매틱(Programmatic) 광고 생태계의 뒷골목은 수십 개의 기술 벤더들이 얽히고설킨 거대한 암흑 공급망이다. 그 안에서 당신이 지출한 광고비는 사방에서 떼어가는 수수료와 불투명한 거래 규칙들로 인해 산산조각이 나고 있다. 

---

## 5-1. 광고비 1달러의 여정: Tech Tax와 50%의 유실

광고주가 온라인 디스플레이 배너나 동영상 광고를 위해 1달러를 집행했을 때, 그 광고가 노출되는 신문사나 블로그 등 매체사(Publisher)에게 실제로 흘러 들어가는 돈은 얼마일까?

글로벌 광고주 협회(ANA)와 애드테크 분석 기관인 자운스 미디어(Jounce Media)의 조사 결과는 참담하다. 광고비의 대략 **50%가 중간 공급망에서 수수료로 소실**된다. 이 잃어버린 수수료를 업계에서는 **'테크 택스(Tech Tax)'**라고 부른다.

```
[ 광고주 예산: $1.00 ]
      │
      ├─▶ DSP (광고주 구매 플랫폼 수수료)   : 15-20% 감액
      ├─▶ DMP (데이터 타겟팅 솔루션 비용)   : 10% 감액
      ├─▶ Verification (검증 솔루션 수수료)  : 5% 감액
      ├─▶ SSP (매체사 판매 플랫폼 수수료)   : 15-20% 감액
      │
      └─▶ [ 실제 매체사의 광고 수익: $0.50 내외 ]
```

광고주가 쓴 돈은 구매 플랫폼(DSP), 타겟팅 데이터 제공사(DMP), 사기 검증 회사(Verification), 그리고 매체사의 지면을 모아 파는 플랫폼(SSP)을 거치며 쪼개진다. 
이 과정에서 심각한 문제는 거래의 '불투명성'이다. 중간 단계의 플랫폼들은 낙찰 가격이나 수수료율을 양쪽에 투명하게 밝히지 않는다. 양방향에서 수수료를 떼어가며 자신들의 배를 불릴 뿐이다. 마케터는 1달러어치의 광고 노출 효과를 샀다고 생각하지만, 실제로 타겟 사용자에게 도달한 물리적 에너지는 50센트 수준으로 축소되어 있다.

## 5-2. 브랜드 세이프티(Brand Safety)의 역설

광고주들은 자신들의 품격 있는 광고가 테러, 포르노, 혹은 극단적 가짜 뉴스 사이트에 실리는 것을 끔찍하게 싫어한다. 이를 예방하기 위해 애드테크 공급망은 **'브랜드 세이프티(Brand Safety)'** 검증 툴을 도입했다. 이 툴들은 특정 키워드(예: '폭탄', '사망', '총기')가 포함된 기사 페이지에는 광고 노출을 자동으로 차단한다.

하지만 여기에는 기이한 역설이 존재한다.

1. **저품질 사이트의 우회:** 진짜 사기꾼들이 운영하는 MFA(Made for Advertising) 스팸 사이트들은 브랜드 세이프티 차단 목록을 아주 쉽게 피한다. 그들은 민감한 뉴스 기사 대신 무해하고 영양가 없는 낚시성 정보(예: "세계에서 가장 아름다운 고양이 10선")만 복사해서 붙여넣기 때문이다.
2. **진짜 매체의 고사:** 정작 사회적 고발을 이끄는 뉴욕타임스나 가디언 같은 고급 저널리즘 사이트들은 전쟁, 테러, 정치 갈등을 보도한다는 이유로 광고 노출이 차단된다.
3. **수수료 갈취의 도구:** 검증 솔루션사들은 광고주에게 "우리가 위험을 막아주고 있다"며 노출당 수수료를 추가로 징수하지만, 실제 광고 사기 봇이나 MFA 유령 사이트는 잡아내지 못하고 양질의 뉴스 매체들의 목줄만 죈다.

결국 브랜드 세이프티 기술은 광고주의 돈을 추가로 뜯어내는 또 하나의 Tech Tax 요율로 작동하고 있을 뿐이다.

## 5-3. 독점의 카르텔: 구글 반독점 판결과 비밀 프로젝트

이 지저분하고 왜곡된 애드테크 공급망의 절대 군주가 바로 구글이다. 
2025년 4월, 미국 연방법원의 레오니 브린케마 판사는 미국 법무부(DOJ)가 제기한 소송에서 구글의 애드테크 독점에 대해 유죄 판결을 내렸다. 이 역사적인 재판에서 구글이 경쟁자를 말살하고 시장을 통제하기 위해 조작해 온 비밀 알고리즘들의 판도라 상자가 열렸다.

```
   ┌───────────────────────────────────────────────┐
   │             [ 구글의 독점 카르텔 ]             │
   │                                               │
   │  Google Ads (구매) ──▶ AdX (거래소) ──▶ DFP (판매)  │
   │       │                   ▲                   │
   │       │                   │                   │
   │       └─▶ [Project Bernanke] 입찰가 도용          │
   │                                               │
   │  * 경쟁 헤더 비딩 방어: [Project Poirot] 90% 인하   │
   │  * 독점 거부 매체 징벌: [Project Bell] 단가 삭감      │
   └───────────────────────────────────────────────┘
```

### ❶ Project Bernanke (프로젝트 버넌케): 경매장의 내부자 거래
구글은 광고 구매 도구(Google Ads)와 광고 거래소(AdX), 매체사 서버(DFP)를 모두 독점적으로 지배하고 있었다. 
구글은 프로젝트 버넌케를 통해 타사 광고 구매 도구(DSP)들이 제시하는 입찰 가격 정보들을 실시간으로 도용했다. 그리고 구글의 광고 구매 툴을 쓰는 광고주가 타사와의 경매에서 간발의 차이(예: 단 1센트 높은 가격)로 낙찰받을 수 있도록 입찰액을 내부적으로 보정(Nudge)해 주었다. 
여기에 필요한 돈은 퍼블리셔(매체사)들에게 정산해 줄 대금에서 조용히 공제했다. 경매장 주인이 특정 구매자와 짜고 판매자의 주머니를 털어 낙찰을 밀어준 명백한 내부자 거래였다.

### ❷ Project Poirot (프로젝트 푸아로): 경쟁자의 싹을 자르다
매체사들이 구글의 독점적 횡포에서 벗어나기 위해 타사 거래소들과 동시에 경쟁 입찰을 붙이는 '헤더 비딩(Header Bidding)' 기술을 도입하자, 구글은 프로젝트 푸아로를 가동했다.
구글의 대형 광고 구매 도구(DV360)는 입찰을 시도할 때, 해당 광고 지면이 구글을 우회해 경쟁사의 헤더 비딩 거래소로 유입되는 것이 감지되면 **입찰 단가를 최대 90%까지 스스로 후려쳐 떨어뜨렸다**. 
이로 인해 헤더 비딩을 사용하는 매체사들의 광고 낙찰 수익이 박살 났고, 매체사들은 두려움에 떨며 헤더 비딩을 포기하고 구글의 양식장 안으로 다시 기어 들어왔다.

### ❸ Project Bell (프로젝트 벨): 복종하지 않는 자에게 내리는 징벌
구글은 자신들의 광고 거래소(AdX)에 우선 입찰 권한을 부여하지 않고 타사 애드테크 도구와 파트너십을 맺으려 시도하는 매체사들에게 **20-30%의 입찰 단가를 인위적으로 삭감**하는 벌칙 알고리즘(Project Bell)을 적용했다. 이는 매체사들이 구글 이외의 다른 대안 기술을 탐색하는 것을 차단하는 물리적 족쇄였다.

### ❹ Jedi Blue (제다이 블루): 거인들의 비밀 담합
가장 추악한 밀약은 메타(당시 페이스북)와의 거래였다. 메타가 헤더 비딩 진영에 합류해 구글의 독점망을 깨려 하자, 구글은 메타에게 구글 경매장(AdX) 내에서 **입찰 속도 우대, 낙찰 성공률 보장, 그리고 막대한 수수료 감면(리베이트)** 혜택을 주는 대가로 헤더 비딩 동맹에서 탈퇴하도록 만들었다. 

이것이 오늘날 우리가 마주한 '효율적인 디지털 광고 시스템'의 날것 그대로의 민낯이다. 구글이 설계한 20-30%의 수수료는 자유 경쟁의 대가가 아니라, 기술 장벽과 조작으로 강제해 낸 **독점 세금(Monopoly Rent)**이었다.

## 5-4. 국내 플랫폼의 한계: 카카오 인앱 브라우저와 다크 소셜의 함정

글로벌 플랫폼에 구글과 메타가 있다면, 한국 시장에는 네이버와 카카오라는 독자적인 가두리 양식장이 존재한다. 국내 마케터들은 이 국내 거인들이 구축해 놓은 기술적 한계와 데이터 유실 문제로 골머리를 앓고 있다. 

가장 대표적인 현상이 카카오톡의 **인앱 브라우저(In-App Browser)**가 만들어내는 **'다크 소셜(Dark Social)'** 데이터 증발 현상이다.

```
[ 카카오톡 링크 클릭 ] ──▶ [카카오 인앱 브라우저 실행] ──▶ GA4 유입 감지: "Direct / (none)"
                                                                (Referrer 정보가 차단되어 유입 출처 실종)
```

### 사칭당한 '직접 유입'
소비자들은 카카오톡 대화방에서 서로 유용한 상품 링크나 블로그 링크를 활발하게 공유한다. 사용자가 그 링크를 클릭하면 스마트폰의 기본 브라우저(크롬, 사파리)가 아니라 카카오톡 앱 내부에서 렌더링되는 '인앱 브라우저'가 열린다. 

이때 구글 애널리틱스(GA4) 같은 웹 로그 분석 툴은 거대한 벽에 부딪힌다. 카카오 인앱 브라우저는 보안과 독점 유지를 이유로 이전 페이지 정보인 **리퍼러(Referrer) 값을 웹사이트에 전달하지 않고 차단**해 버린다. 

결과적으로 GA4는 이 트래픽을 어디서 왔는지 알 수 없는 **'Direct / (none) (직접 유입)'**으로 강제 분류한다. 
마케터는 *"와, 우리 브랜드를 주소창에 직접 치고 들어오는 충성 고객이 이렇게 많구나!"*라고 착각하지만, 실제로는 카카오톡 대화방을 통해 바이럴된 트래픽(다크 소셜)이 측정 불능 상태가 되어 직접 유입으로 오인 처리된 것일 뿐이다. 이로 인해 소셜 바이럴 마케팅의 정확한 기여(Attribution) 측정은 불가능해진다.

## 5-5. 네이버 검색 광고와 브랜드 인지도의 혼동

네이버 쇼핑과 검색 광고 영역에서도 이와 유사한 기만이 발생한다. 
네이버 모바일 화면의 검색 광고 영역은 유저 클릭 시 높은 전환율을 보여준다. 네이버 검색 광고의 ROAS는 종종 수백 %에 달한다. 

하지만 냉정하게 분석해 보면, 소비자가 네이버에서 '특정 제품명'이나 '특정 브랜드'를 상세히 입력해 검색했다는 것은, 이미 다른 소셜 미디어나 외부 미디어(유튜브, 블로그 등)에서 광고를 보고 인지도를 획득한 후 **결제 직전의 마지막 경로로 네이버를 통과하고 있는 것**에 불과하다. 

네이버 검색 광고는 인과적으로 수요를 '창출(Create)'한 것이 아니라, 이미 다른 곳에서 생성되어 흘러온 수요를 결제 직전에 '포획(Capture)'했을 뿐이다. 
그럼에도 마케터들은 네이버 대시보드에 찍히는 마지막 성과 수치에만 목을 매며, 정작 실제 수요를 창출해 주었던 상위 퍼널(Upper Funnel) 미디어 광고비를 삭감하고 네이버 광고비를 늘리는 최악의 의사결정을 내린다. 그 결과는 외부 인지도 유입의 중단과 네이버 전환 수의 동반 폭락으로 이어진다.

## 5-6. 이 장을 덮기 전에 — 애드테크 공급망을 감사하라

당신의 비즈니스가 플랫폼의 함정에서 벗어나기 위해 아래 질문에 답할 수 있는지 자문하라.

1. **우리가 지출하는 광고비 중 중간 수수료(Tech Tax)로 새어나가는 비율을 명확하게 규정할 수 있는가?**
   - 공급망 경로 효율성 감사(SPO, Supply Path Optimization)를 수행하여 불필요한 중간 중개 거래소를 쳐내야 한다.
2. **카카오톡 공유를 통해 들어오는 다크 소셜 트래픽을 UTM 파라미터나 서버사이드 데이터로 추적하고 있는가?**
   - 수동으로 UTM 태깅이 되지 않은 트래픽은 데이터의 블랙홀로 사라져 당신의 의사결정을 교란하고 있다.
3. **네이버 검색 광고의 성과가 '수요 창출'인지 '단순 포획'인지 구분하기 위해 홀드아웃(Holdout) 실험을 해본 적이 있는가?**
   - 네이버 광고비를 일시적으로 20% 줄였을 때, 전체 쇼핑 매출에 어떤 증분(Incrementality) 변화가 생기는지 직접 확인해야만 비로소 진짜 숫자가 보이기 시작한다.
